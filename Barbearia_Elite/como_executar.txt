

# COMO ACESSAR E EXECUTAR O SISTEMA PELO LINK DO RENDER 

## Barbearia Elite

O sistema Barbearia Elite está hospedado na plataforma Render, permitindo o acesso diretamente pelo navegador, sem precisar instalar programas ou configurar o ambiente local.

### 1. Acessar o sistema

Para acessar, basta abrir o navegador e entrar no endereço:

https://barbearia-elite-0dr0.onrender.com/

### 2. Iniciar o sistema

Após acessar o endereço, aguarde o carregamento da página.

**Observação:** Como o serviço utiliza o plano gratuito do Render, pode ser necessário aguardar alguns instantes caso esteja inativo.

### 3. Utilizar as funcionalidades

Com o sistema aberto, é possível utilizar as funcionalidades disponíveis:

- Cadastrar e consultar clientes;
- Cadastrar e consultar barbeiros;
- Cadastrar e consultar serviços;
- Criar e consultar agendamentos;
- Atualizar e excluir registros, conforme as funcionalidades disponíveis.

### 4. Requisitos para acesso

- Computador, tablet ou celular;
- Navegador de internet;
- Conexão com a internet.

Não é necessário instalar Python, Flask, SQLite ou outras ferramentas para utilizar o sistema hospedado.

### 5. Hospedagem

O projeto foi publicado utilizando a plataforma Render, responsável por disponibilizar o sistema na internet.

**Link de acesso:** https://barbearia-elite-0dr0.onrender.com/
