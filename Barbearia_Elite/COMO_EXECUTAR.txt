# Como executar o projeto — Barbearia Elite

Este documento apresenta um roteiro para executar o projeto localmente.

## 1. Requisitos

- Python instalado.
- Git (opcional, caso o projeto seja baixado pelo repositório).
- Editor de código, como Visual Studio Code.

## 2. Obter os arquivos

Baixe o projeto pelo GitHub ou clone o repositório:

```bash
git clone https://github.com/guelznsxl/barbearia_elite.git
```

Entre na pasta do projeto. Se o repositório tiver uma pasta externa chamada `Barbearia_Elite`, entre nela antes de continuar.

## 3. Criar um ambiente virtual (recomendado)

No terminal, dentro da pasta principal do projeto:

```bash
python -m venv venv
```

No Windows, ative o ambiente:

```bash
venv\Scripts\activate
```

## 4. Instalar as dependências

```bash
pip install -r requirements.txt
```

## 5. Conferir os arquivos do banco

O arquivo de criação das tabelas deve estar em:

```text
sql/banco/schema.sql
```

O arquivo `py/database.py` deve apontar para esse mesmo caminho. No projeto atual, a configuração esperada é:

```python
PASTA_BANCO = PASTA_PROJETO / "sql" / "banco"
DATABASE = PASTA_BANCO / "barbearia.db"
ARQUIVO_SQL = PASTA_BANCO / "schema.sql"
```

O banco SQLite é criado/aberto pela função `criar_banco()` da aplicação.

## 6. Iniciar a aplicação

A partir da pasta principal do projeto, execute:

```bash
python py/app.py
```

Se o arquivo `app.py` estiver configurado para iniciar o servidor local, o terminal mostrará o endereço de acesso.

Abra no navegador o endereço local indicado no terminal, normalmente:

```text
http://127.0.0.1:5000
```

## 7. Hospedagem

A versão publicada está hospedada no Render. Para conferir o endereço atual, acesse o painel do Render e abra o serviço da Barbearia Elite.

## 8. Solução de problemas

- **Erro de módulo não encontrado:** confira se o ambiente virtual está ativo e execute novamente `pip install -r requirements.txt`.
- **Erro ao abrir o banco:** confira se a pasta `sql/banco` existe e se contém `schema.sql`.
- **Página não abre:** confira a mensagem exibida no terminal e os logs da aplicação.
- **Porta em uso:** encerre outro processo que esteja utilizando a mesma porta ou configure uma porta diferente conforme o código da aplicação.
